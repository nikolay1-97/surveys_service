# Заметки по логике работы приложения.
Пользователь может просматривать опросы, вопросы и опции для вопросов по отдельности и так же
пользователь может получить информацию об опросах в виде одного объекта, включающего
всю информацию о каждом опросе("/surveys/all-info").

Админ может просматривать результаты опросов по id опроса ("/answers-options/{survey_id}").

Для ответов на вопросы типов одиночный выбор и множественный выбор, в поле "answer" необходимо
передать пустую строку.

Для ответа на вопрос типа текстовое поле, в поле "answer" необходимо передать ответ на вопрос.
# Подготовка к запуску приложения.
Для запуска приложения нужно установить значения для слудующих
переменных в файле "/.env":

    PORT- порт;

    DB_URL= адрес базы данных;

    SALT- значение для шифрования пароля;

    ADMIN_SECRET- значение для генерации токена для админа;

    USER_SECRET- значение для генерации токена для пользователей;

    EXPIRE_JWT- время действия токена.
## Установка зависимостей.
Для установки зависимостей необходимо выполнить команду "npm install" в 

терминале из корневой директории.
## Выполнение миграций.
Для выполнения миграций необходимо выполнить команду "npx knex migrate:latest"

в терминале из директории "/src/db.
## Создание админа.
Для создания админа необходимо выполнить команду "npx knex seed:run --specific=create_admin.ts"
## Заполнение базы данных тестовыми данными.
Для заполнения базы данных тестовыми данными необходимо выполнить команду
"npx knex seed:run --specific=createTestData.ts" в терминале из директории "/src/db".
## Запуск тестов.
Перед каждым запуском тестов необходимо выполнять команду
"npx knex seed:run --specific=createTestData.ts" в терминале из директории "/src/db" для заполнения базы даных
тестовыми данными.

Для запуска тестов необходимо выполнить команду "yarn test" в терминале из корневой директории.
## Запуск приложения.
Для запуска приложения необходимо выполнить команду "npm run start:dev"

в терминале из корневой директории.

Api документация доступна по ссылке "http://127.0.0.1:порт/api".
